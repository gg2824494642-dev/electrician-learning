# 电工学堂 · 网站说明

纯公益、全站免费的电工学习网站。**双击 `index.html` 即可打开**（Chrome / Edge），
不需要服务器、不需要联网、没有构建步骤。

内容整合自你提供的三份资料 + 一个在线站点，并做了跨来源去重：

| 来源 | 提供了什么 | 说明 |
|---|---|---|
| 低压电工一站式学习手册（238 KB） | **课程讲义正文**（电学基础十章 + 第 1~9 章）+ 例题、口诀、速记表 | 主源；经比对，另两份专题教程的正文已被该手册完整收录 |
| 低压电工每日学习表（33 KB） | **70 天学习计划**、考试信息、报考费用、备考贴士 | 10 周 70 天逐日任务，含 B 站搜索链接 |
| 五套练习卷（含答案解析）+ 在线站点题库 | **题库 293 题**（判断 180 / 单选 93 / 多选 20） | 逐题核对答案与解析，按模块归类 |
| 在线站点（电工自学成长站） | **通俗知识库 12 条**、**B 站名师 9 位**、**补充实操课程 2 门 7 节** | 只保留本地资料没有覆盖的内容 |

最终规模：**12 门课程 / 50 节讲义（其中 1 篇配图精讲）· 293 道题 · 70 天计划 · 17 项资料 · 41 条已核实视频 · 48 张手绘配图**。

## 关于题库（第 3 条需求的说明）

「与国家考试题库一样并实时更新」在技术上做不到：**官方低压电工考题库不对外公开，也有版权限制**，任何第三方站点都无法同步。
本站能做到、也已经做到的是：

1. **题型对齐官方理论机考**：判断题 + 单选题（另有多选题作为拓展）；
2. **考点按官方大纲覆盖**：题库分 6 个模块（电气安全技术 / 电工基础 / 安全生产法规 / 低压设备 / 电机控制与线路照明 / 应急急救处置）；
3. **每题都有解析**，293 题全部人工核对过答案与解析；
4. **页面显著位置标注**「本站题目不等同于、也无法代替真实考题」；
5. 提供 `scripts/import_questions.py`，拿到新题（Excel / CSV / JSON）一条命令合并进题库。

```powershell
python scripts/import_questions.py 新题.xlsx        # 自动校验题型 / 答案 / 去重
python scripts/build_site_data.py                   # 重新打包数据
```

## 一、怎么打开

**方式一（推荐）**：双击 `site/index.html`。

已实测：Chrome 在 `file://` 协议下 `localStorage` 可用，所以学习进度、笔记、错题本、
收藏、打卡记录都能正常保存（数据存在你自己的浏览器里，换浏览器/换电脑不同步）。

**方式二（可选）**：在 `site` 目录执行 `python -m http.server 8080`，访问 http://localhost:8080 。

## 四、内容是怎么去重的

1. **三份本地资料之间**：`电学基础教程_电流电压电阻功率.html`、`电工基础概念全解_串并联交流电电容电感.html`
   的正文经逐节比对，已被《一站式学习手册》完整收录 → 只保留一份，按主题合并进 10 门课程。
2. **跨课程重复**：安全电压等级只在「安全用电基础」讲全，基础课只留一句并注明「见该课」；
   漏电保护器原理只在「安全用电基础」，配电箱分路处只用一行「回顾」；灭火器表只在「安全用具与标识」，
   急救课只讲扑救顺序与安全距离；测量接法细节集中到「电工仪表」等。
3. **题库去重**：同一题出现在练习卷 HTML、`build_quiz.py`、手册内嵌卷、在线站点四处的，
   按题干归一化（去空白与标点）比对，合并 7 组；在线站点 40 题中 32 题不重复被并入。
4. **与在线站点之间**：在线站点的「基础理论 20 节 / 安全规范 17 节 / 实操技能 20 节」经核对与本地资料
   实质重复，**只保留了真正独有的部分**：故障排查实录、导线绝缘恢复、端子压接、基尔霍夫定律、
   二极管与变压器、三相电机改单相、自动往返控制、色环电阻、级差保护等 → 形成 12 条知识库 + 2 门补充课。
5. **资讯与知识库**：`news.json`、`knowledge.json` 中标明「本站整理」，只使用源资料已有的事实，
   未新增任何政策条号、日期或数字；涉及数值处均提示以课程正文与官方标准为准。

## 五、怎么更新内容

```powershell
# ① 改课程 / 题库 / 计划等数据后，重新打包（必须）
python scripts/build_site_data.py

# ② 抓最新行业资讯（从 6 个官方渠道）
python scripts/update_news.py --limit 12
python scripts/build_site_data.py          # 抓完要再打包一次才会在页面生效

# ③ 导入新题目（Excel / CSV / JSON，自动校验与去重）
python scripts/import_questions.py 新题.xlsx
python scripts/build_site_data.py

# ④ 重新生成配图（改了 scripts/fig_*.py 之后）
python scripts/build_figures.py
```

精讲讲义的数据格式：改 `data/detail-lessons/*.json`，支持
`h2 / p / ul / table / note / tip / warn / example / svg` 九种内容块。

**配图是怎么画的（V1.2 起全部改为「图解卡」）**：全站 48 张图解统一成
**「实物组件图 + 标注框 + 蓝色箭头 + 绿色 ✓ 结论」**的图解卡版式：

- `scripts/svgkit_pro.py`：**实物级组件库**（微型断路器、漏电保护器、接触器、三相异步电动机、
  数字万用表、兆欧表、钳形电流表、86 型插座/开关、电缆剖面、灭火器、绝缘用具、CPR 假人…），
  用渐变 + 高光 + 暗部表现塑料壳体体积，铜色端子螺丝、按国标配线色（L1 黄 / L2 绿 / L3 红 / N 淡蓝 / PE 黄绿双色），
  丝印文字（C63 / 30mA / T / R / KM / A1A2）都是矢量文字，**结构细节可控、文字永不错乱**；
- `scripts/figcard.py`：图解卡排版器（标题标签、扇出箭头、标注框、结论条）；
- `scripts/figures_v2.py`：12 张课程封面 + 12 张知识库图解；
- `scripts/figures_lab_v2.py`：4 张科目总览 + 20 张实操考核要点图解。

> **为什么不用 AI 生图**：实测免费的文本生图模型（Flux 通道）画出来的「三极断路器」结构完全不对
> （极数、手柄、端子全错，还带水印）。本项目的硬要求是「必须跟实物结构一样」，
> 所以改用**自绘高保真矢量组件**：结构由代码保证，永远不会画错，也不用担心中文乱码。

预览：打开 `prototype/figures-preview.html` 可以看到全部 48 张图解卡。
